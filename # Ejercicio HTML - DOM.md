## Introducción
[El Document Object Model, conocido por sus siglas DOM, es una interfaz de programación que representa documentos HTML y XML como una estructura de árbol compuesta por nodos. Cuando un navegador carga una página web, toma el código HTML y lo transforma en un modelo de objetos que JavaScript puede entender y manipular. Con el método  podemos "escuchar" estos eventos y ejecutar una función específica cuando ocurran, lo que da lugar a la interactividad que vemos en aplicaciones web modernas. En clase vimos que entender la relación padre-hijo-hermano entre nodos es clave, porque muchas veces necesitamos navegar desde un elemento a otro para modificar partes relacionadas de la página. En resumen, el DOM actúa como un puente entre el contenido HTML estático y los lenguajes de programación como JavaScript, permitiendo que las páginas web respondan a las acciones del usuario y se actualicen sin necesidad de recargar completamente.]
## Reflexión
[A mí me parece que el DOM es una de las herramientas más útiles que hemos visto en clase porque es lo que realmente le da vida a una página web. Antes de entender el DOM, el HTML y CSS solo me servían para hacer páginas estáticas, como si fueran un cartel impreso. Pero ahora que sé que JavaScript puede entrar al DOM y cambiar cualquier cosa en tiempo real, entiendo cómo funcionan las páginas que uso diario como YouTube o Instagram. Me parece súper práctico porque con solo aprender a seleccionar elementos y cambiar sus propiedades ya puedo hacer que un botón muestre y oculte información, que un formulario valide datos antes de enviarse, o que una imagen cambie cuando paso el mouse. Creo que es la base para cualquier cosa que quiera hacer en desarrollo web a futuro, desde una página sencilla hasta una aplicación completa. Sin el DOM, todo el JavaScript que aprendamos no tendría dónde aplicarse.
]
## Conclusión
[Para concluir, el Document Object Model es la pieza fundamental que conecta la estructura de una página web con la lógica de programación. Como se sintetizó anteriormente, el DOM representa todo el HTML como un árbol de nodos que podemos recorrer, leer y modificar usando JavaScript. Esta capacidad de manipular elementos, estilos y eventos es lo que transforma un documento fijo en una experiencia interactiva para el usuario. Reflexionando sobre su utilidad, queda claro que dominar el DOM no es opcional si se quiere trabajar en desarrollo web, ya que es el puente que permite que nuestras ideas y código se conviertan en acciones visibles dentro del navegador. En pocas palabras, entender el DOM es entender cómo hacer que la web responda.]
