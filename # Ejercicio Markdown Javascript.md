# Ejercicio Markdown Javascript
## Introducción
En este documento se abordará el tema de JavaScript, el lenguaje de programación que permite agregar interactividad y dinamismo a las páginas web. Mientras que HTML estructura el contenido y CSS define la presentación visual, JavaScript es el encargado de controlar el comportamiento y la lógica. Gracias a JavaScript, una página puede responder a las acciones del usuario, validar formularios, crear animaciones, comunicarse con servidores y actualizar contenido sin recargar. Es considerado uno de los tres pilares fundamentales del desarrollo web frontend, junto con HTML y CSS.
## Síntesis
JavaScript es un lenguaje de programación interpretado, de alto nivel y orientado a objetos que se ejecuta principalmente en el navegador del cliente. Fue creado en 1995 por Brendan Eich y su principal propósito es manipular el Document Object Model, o DOM, para hacer que las páginas web sean interactivas. A diferencia de HTML y CSS, que son lenguajes de marcado y estilo, JavaScript permite definir variables, estructuras de control como condicionales `if/else` y bucles `for` o `while`, y funciones que encapsulan bloques de código reutilizable. Se puede incluir en un documento HTML mediante la etiqueta `<script>`, ya sea escribiendo el código directamente entre las etiquetas o enlazando un archivo externo con el atributo `src`.
Uno de los usos más importantes de JavaScript es la manipulación del DOM. El DOM es la representación en forma de árbol de todos los elementos de una página HTML. Con JavaScript podemos seleccionar cualquier nodo usando métodos como `document.getElementById()`, `document.querySelector()` o `document.getElementsByClassName()`. Una vez seleccionado, es posible modificar su contenido con `textContent` o `innerHTML`, cambiar sus estilos CSS a través de la propiedad `style`, o añadir y quitar clases con `classList`. También podemos crear elementos nuevos con `document.createElement()` y agregarlos a la página con `appendChild()`, o eliminarlos con `remove()`. Esta capacidad es la base de cualquier aplicación web moderna.
Además de manipular elementos, JavaScript maneja eventos para responder a las acciones del usuario. Con `addEventListener()` podemos "escuchar" eventos como `click`, `mouseover`, `keydown` o `submit` y ejecutar una función cuando ocurran. Esto permite validar un formulario antes de enviarlo, mostrar un menú desplegable al pasar el mouse, o cambiar una imagen al hacer clic en un botón. JavaScript también maneja la asincronía mediante `setTimeout`, `Promises` y `async/await`, lo que permite hacer peticiones a servidores con `fetch()` para obtener datos sin congelar la página. ## Conclusión
En conclusión, JavaScript es el lenguaje que transforma documentos HTML estáticos en aplicaciones web interactivas y dinámicas. Como se sintetizó, su capacidad para manipular el DOM, gestionar eventos y trabajar de forma asíncrona lo convierte en una herramienta indispensable para el desarrollo frontend. Reflexionando sobre su utilidad, queda claro que aprender JavaScript no es solo aprender otro lenguaje, sino aprender a darle comportamiento y lógica a nuestras páginas. Dominar sus conceptos básicos de variables, funciones y manipulación del DOM es el primer paso para construir cualquier tipo de proyecto web moderno, desde una simple calculadora hasta una red social completa.
