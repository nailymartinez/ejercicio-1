# Ejercicio MarkDown CSS

## Introducción

En este documento se abordará el tema de CSS, Cascading Style Sheets o Hojas de Estilo en Cascada. CSS es el lenguaje que utilizamos en desarrollo web para definir la presentación visual de un documento HTML. Mientras que HTML se encarga de la estructura y el contenido, CSS define los colores, tipografías, espaciados, posicionamiento y animaciones. Sin CSS, todas las páginas web se verían prácticamente iguales: texto negro sobre fondo blanco, sin diseño ni identidad visual. Por eso, entender CSS es fundamental para crear sitios atractivos y profesionales.

## Síntesis

CSS, que significa Cascading Style Sheets u Hojas de Estilo en Cascada, es el lenguaje utilizado para describir la presentación de documentos HTML. Su función principal es separar el contenido de la presentación, lo que permite que un mismo HTML pueda tener múltiples diseños sin modificar su estructura. CSS funciona mediante reglas que se componen de un selector y un bloque de declaraciones. El selector apunta a qué elemento de HTML se le aplicará el estilo, como `p`, `.clase` o `#id`, y el bloque de declaraciones va entre llaves `{}` conteniendo propiedades y valores, por ejemplo `color: blue;` o `font-size: 16px;`. La palabra "cascada" se refiere a que los estilos pueden heredarse y sobreescribirse siguiendo un orden de prioridad: los estilos del navegador, los del usuario, los externos, los internos y los en línea, además de la especificidad de los selectores.

Uno de los conceptos más importantes vistos en clase es el Modelo de Caja o Box Model. Cada elemento en HTML es considerado por CSS como una caja rectangular compuesta por cuatro áreas: el contenido en el centro, el padding que es el espacio entre el contenido y el borde, el border que es la línea que rodea al padding, y el margin que es el espacio exterior que separa la caja de otros elementos. Propiedades como `width` y `height` por defecto solo afectan al contenido, pero con `box-sizing: border-box;` podemos hacer que incluyan también el padding y el border, lo que facilita mucho el cálculo de layouts. Para posicionar estas cajas usamos propiedades como `display`, que define si un elemento es de bloque o en línea, `position` para colocarlo de forma relativa, absoluta o fija, y sistemas modernos como Flexbox y Grid.

Flexbox, o Flexible Box Layout, nos permite distribuir el espacio entre elementos de una forma más eficiente cuando desconocemos el tamaño del contenedor. Con propiedades como `display: flex;`, `justify-content` y `align-items` podemos centrar elementos vertical y horizontalmente en dos líneas de código, algo que antes era muy complicado. CSS Grid es aún más poderoso para diseños bidimensionales, permitiéndonos definir filas y columnas con `grid-template-columns` y `grid-template-rows`. Además, CSS permite hacer diseños responsivos usando Media Queries con `@media`, que aplican estilos diferentes según el tamaño de la pantalla, logrando que una misma página se vea bien en celular, tablet y computadora. En resumen, CSS controla toda la capa visual de la web, desde lo más básico como colores hasta layouts complejos y animaciones con `@keyframes`. **| 387 palabras**

## Reflexión

Para mí, CSS es lo que hace que programar web sea divertido porque es donde realmente ves los cambios. Con HTML solo pones texto y cajas, pero con CSS es cuando la página agarra personalidad. Me parece súper útil porque antes de saber CSS, pensaba que hacer una página bonita era de diseñadores gráficos, pero ahora entiendo que con código puedo controlar cada pixel. Lo que más me gusta es Flexbox, porque centrar cosas antes era un dolor de cabeza y ahora es solo poner `display: flex; justify-content: center;`. También me sirve mucho entender el Box Model porque ya no me pasa que le pongo padding a algo y se me descuadra todo el diseño. Creo que CSS es indispensable si quiero que mis proyectos no se vean como hechos en los 90s.

## Conclusión

En conclusión, CSS es el lenguaje responsable de toda la parte visual y estética de la web. Como se sintetizó, a través de selectores, el Modelo de Caja, y sistemas de layout como Flexbox y Grid, podemos transformar una estructura HTML simple en un diseño complejo, responsivo y atractivo. Reflexionando sobre su utilidad, CSS no es solo "ponerle color" a las páginas, sino que es la herramienta que nos permite comunicar jerarquía, guiar al usuario y crear experiencias agradables. Sin CSS, la web moderna no existiría como la conocemos, por lo que dominar sus conceptos es esencial para cualquier desarrollador frontend.
