# Ejercicio Markdown 03 - HTML MD
## Introducción
En este documento se abordará el tema de HTML y su relación con el Document Object Model, conocido como DOM. HTML es el lenguaje base con el que se estructura toda página web, y el DOM es la representación que el navegador hace de ese código para poder manipularlo. Entender ambos conceptos es esencial para el desarrollo web, ya que uno define la estructura y el otro permite la interactividad.
## Síntesis
El Document Object Model, o DOM por sus siglas en inglés, es una interfaz de programación que representa documentos HTML y XML como una estructura de árbol compuesta por nodos. Cuando un navegador carga una página web, analiza todo el código HTML y lo transforma en un modelo de objetos que JavaScript puede entender y manipular. En esta estructura jerárquica, cada etiqueta HTML se convierte en un objeto llamado nodo o elemento. El nodo principal o raíz de todo el documento es `document`, del cual se desprenden dos ramas fundamentales: `head` y `body`. A partir de ahí, cada elemento puede contener nodos hijos, como párrafos dentro de un `div`, y tener nodos hermanos, como varios elementos `li` dentro de una misma lista `ul`. Esta organización es lo que permite recorrer y modificar el contenido de forma precisa usando código.
La principal utilidad del DOM es convertir una página estática en algo dinámico e interactivo. Mediante JavaScript, podemos seleccionar cualquier elemento del árbol utilizando métodos como `document.getElementById()`, que busca un elemento por su atributo id único, o `document.querySelector()`, que permite usar selectores CSS para encontrar elementos. Una vez seleccionado un nodo, es posible cambiar su contenido de texto con `textContent`, modificar sus estilos CSS a través de la propiedad `style`, e incluso agregar o eliminar clases con `classList` para cambiar su apariencia. También podemos crear nuevos elementos desde cero con `document.createElement()` y agregarlos al árbol con `appendChild()`, o eliminarlos con `removeChild()`.
Además de la manipulación de contenido, el DOM es el encargado de gestionar los eventos. Un evento es cualquier acción que realiza el usuario, como hacer clic en un botón, mover el mouse, o enviar un formulario. Con el método `addEventListener()` podemos "escuchar" estos eventos y ejecutar una función específica cuando ocurran, lo que da lugar a la interactividad que vemos en aplicaciones web modernas. En resumen, el DOM actúa como un puente indispensable entre el contenido HTML estático y los lenguajes de programación como JavaScript, permitiendo que las páginas web respondan a las acciones del usuario y se actualicen sin necesidad de recargar completamente. **| 368 palabras**
## Reflexión
Para mí, lo más útil del DOM es que me hizo entender que HTML no está "muerto" una vez que se carga la página. Antes pensaba que el navegador solo leía el código y ya, pero el DOM me mostró que todo sigue vivo y se puede cambiar en cualquier momento. Esto es clave porque así funcionan todas las apps que usamos: cuando le das like a una foto y el corazón se pone rojo sin recargar la página, eso es el DOM en acción. Saber que puedo agarrar cualquier pedazo de mi HTML y modificarlo con código me quita el miedo a hacer proyectos más complejos, porque ya no dependo solo de lo que escriba en el archivo inicial.
## Conclusión
En conclusión, el DOM es el mecanismo que le da verdadero poder al HTML dentro del navegador. Mientras que HTML define la estructura inicial de un sitio, el DOM es la representación interactiva de esa estructura que nos permite alterarla mediante programación. Como se sintetizó, su modelo de árbol y su sistema de eventos son la base para crear experiencias web dinámicas. Reflexionando sobre su importancia, queda claro que sin el DOM, JavaScript no tendría forma de interactuar con la página, y la web seguiría siendo solo documentos estáticos. Por ello, dominar el DOM es un paso obligatorio para cualquier desarrollador web.
